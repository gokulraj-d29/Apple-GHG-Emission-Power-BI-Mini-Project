# Apple-GHG-Emission-Power-BI-Mini-Project
Apple's Greenhouse Gas Emissions Data Analysis Project
Mini Project Documentation
Project Title
Apple Greenhouse Gas Emissions Analysis Using Excel and Power BI
________________________________________
Project Overview
This project focuses on analyzing Apple’s greenhouse gas emissions, product carbon footprints, and business normalization factors using Microsoft Excel and Power BI. The main objective is to identify sustainability trends, emission patterns, and environmental impacts of Apple products through proper data cleaning, transformation, and visualization techniques.
The project demonstrates how raw environmental data can be converted into meaningful business insights using Excel for preprocessing and Power BI for dashboard creation. The analysis helps understand emission changes over time and highlights products contributing to higher carbon footprints.
________________________________________
Objectives of the Project
•	Analyze Apple’s greenhouse gas emissions data.
•	Identify trends and patterns in emissions over different years.
•	Compare carbon footprints across Apple products.
•	Perform data cleaning and transformation using Excel.
•	Create interactive dashboards and visualizations using Power BI.
•	Generate meaningful sustainability insights for decision-making.

Data Cleaning Tasks Performed in Excel
The following preprocessing steps were completed in Microsoft Excel:
1. Removed Duplicates
Duplicate records were identified and removed to maintain data accuracy.
2. Handled Missing Values
Blank and missing values were checked and corrected using suitable methods.
3. Standardized Formats
Data formats such as dates, text, and numeric values were standardized for consistency.
4. Created Calculated Columns
Additional columns were created for analysis and reporting purposes.
5. Applied Filtering and Sorting
Filters and sorting options were used to organize and analyze the dataset efficiently.
6. Created Pivot Tables
Pivot Tables were created to summarize emissions and product-related information.
________________________________________
Steps Performed in Power BI
1. Imported Cleaned Excel Data
The cleaned dataset from Excel was imported into Power BI.
2. Performed Data Transformation
Power Query Editor was used for additional formatting and transformation.
3. Created Relationships
Relationships between tables were created where required.
4. Built Visualizations
Different visual elements were created to analyze sustainability metrics.
5. Added Interactivity
Slicers and filters were added for dynamic dashboard interaction.
